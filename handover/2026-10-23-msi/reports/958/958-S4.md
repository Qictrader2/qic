## Must-keep items
1. 969 QA fix: role="alertdialog" on every frame including both code steps; Back from a code step and any 409 WITHDRAWAL_FEE_QUOTE_EXPIRED start a new quote session with the fields kept (tested).
2. 920 key binding: every POST goes out under the intent store's key (createMoneyIntentStore keyed by auth user.uid). The intent is network, trimmed address, and exact amountMinor equal to the backend's round(amount*1e6), checked over 2,000 random amounts. The flow is ensure, then markSent (re-ensure on null), then main's useIntentIdempotencyKey.run with that key unchanged, then settle. Replays are answered before step-up on main, so Start again sends the same key with a new code. A pending key opens Check status first (N9), including when the retyped amount now fails validation.
3. Amount freeze: Review snapshots the intent; a re-quote, Max or rate change never changes the amount under a held key; Start again and Try this withdrawal again reuse the snapshot (tested after a transport failure plus fee and rate changes).
4. Check status via GET /api/v1/money-requests/{key} (958-S1 hook). A completed withdrawal reads its own row for the fee and transaction ID (B8c). "Hasn't reached us" only after WITHDRAWAL_REQUEST_TIMEOUT_MS = 120 s: the POST has no client timeout, Heroku answers 503 at 30 s while the dyno keeps working, and Solana sends can hang past 30 s. A lookup before that reads "We can't see it yet. It may still be on its way, so check again in a moment."
5. A failed lookup reads "Cancelled", never "balance restored".
6. Dialog-level Escape test inside the network rows at 390 and 1440. A control case proves it fails when a child swallows Escape. A React-level stopPropagation cannot swallow it, because Radix listens on document capture.
7. Too-many-codes is read from the 429 status and RATE_LIMITED code via lib/step-up-code-errors.ts (coordinator note after 958-S5). The boards' "in a few minutes" wording stays. Withdraw reads no system or treasury status, so systemStatusUnavailable needs no handling here.
